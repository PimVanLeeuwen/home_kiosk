The message page

What a tap on a notification opens: /alerts/{id}, the message's own page in the hub, for 7 days. The full message as Telegram would show it (bold, quotes, links), its picture (step 4), whether the problem is still open, an explanation on request, the way onward, and what came before. The same page opens from the message log on the Alerts page.

On the phone

From the banner to the page. The banner is ntfy's (title with the dot, four lines, the thumbnail); everything else is the hub's.
