Code on Repos example data

The House panel's Code screen in the hub: a Code card at the top of the Repos page with your last 16 weeks of GitHub activity as a grid, and beside it the latest build of each default branch and the open pull requests of your and Hubble's repos, a failing build first.

Activity

  • Your GitHub contribution calendar (commits, pull requests, reviews and issues, private ones counted too), the same numbers as on your profile, for the last 16 weeks: a column per week from Monday, today outlined, the days still to come left empty.
  • Five levels in the accent violet, the busiest days glowing; GitHub's own quartiles decide the level.
  • Below: contributions in 16 weeks, this week, and the current streak of days in a row.

Builds and pull requests

  • Your and Hubble's repos (not GEWIS): the latest build of each default branch with CI, newest first, at most six; a failing build always on top, tinted red with a pulsing dot; a running one breathes amber.
  • Open pull requests below with their own check state, drafts marked.
  • The card's pill: N failing, else N running, else All green. Read with the Repos data every 30 minutes, nothing extra from GitHub's rate limit worth noting (one more field per repo, one query for the calendar).
