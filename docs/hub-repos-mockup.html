Repos, restyled example data

The Repos page in the language of the other restyled pages: owner tabs in a glass track, four tiles for the owner (repos and languages, CI, pull requests and issues, the backup), and repo cards lit along the top in their language's colour, a failing build tinted red. Same data as today.

What changes

  • Header: as today, plus an All green / N failing pill for the tab you are on.
  • Owners: Mine, Hubble and GEWIS as a glass segmented control with their counts.
  • Four tiles: repos with a bar of their languages; CI as a dot per repo (green, amber running, red failing and pulsing, grey without CI); open pull requests and issues; and the backup with when the mirror last ran and how long the token lasts.
  • Filter and forks: a glass search field and the forks switch as on Alerts.
  • Repo cards: a thin glowing line along the top in the language's colour; name, Private and Fork chips, the description; language, stars, forks and when it was pushed, with a thin bar for how recent that is (fuller is fresher, over 90 days); CI as a glowing dot and word, pull requests and issues as small chips (lit when there are any), the backup mark and the latest release. A failing build tints the card red.
  • Not here: the 16-week commit grid of the Code panel; the hub does not collect commit activity yet (that comes with the Code screen in M20).
