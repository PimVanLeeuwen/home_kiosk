Docker, restyled example data

The Docker page in the language of the restyled Home, NAS and Backups: four instrument tiles, a segmented order switch, rows with glowing status dots and CPU lines and thin load bars, glowing 24-hour areas when a row opens, and the image updates as a timeline. Same data as today.

What changes

  • Header: as today, plus an All running / N need a look pill.
  • Running: the count with a dot per container, unhealthy amber and stopped red (pulsing).
  • CPU, all containers: the share of the NAS with the three busiest containers as bars. Memory: the total as one bar split by the biggest users, the rest in grey.
  • Updates, last 7 days: the count with a bar per day, lit on days with an update.
  • Filter and order: a glass search field and a segmented switch (By stack, CPU, Memory, Name) instead of a select.
  • Containers: per stack a heading with a tinted count; each row with a glowing status dot (pulsing when it needs a look), name and image, a glowing 24-hour CPU line, CPU and memory with a thin load bar, and network; a stopped or unhealthy row is tinted. Opened, two glass panels with the 24-hour CPU and memory areas (as on the NAS page) and the status, image and last update.
  • Image updates: a timeline, newest first, with the container, image and the old and new image ids as chips (the new one lit).
